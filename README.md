# FitTrack – MongoDB + PyMongo

1. Start MongoDB (local `mongod` or set `MONGO_URI` to an Atlas string).
2. `pip install -r requirements.txt`
3. `python seed.py` – creates collections with validators and sample data.
4. `python main.py` – menu (option 13 = full demo for screenshots).
5. `mongosh --file queries.js` – equivalent shell queries.
